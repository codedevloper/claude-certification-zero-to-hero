# Roadmap

This is the project roadmap: what is planned for the repository itself. If you are looking for a **study plan**, see
the [learning roadmaps](00-getting-started/roadmaps/README.md).

Current status, file by file, is tracked in [PROGRESS.md](PROGRESS.md).

## v1.0: foundation release (current)

- [x] Certification registry verified against the official v1.0 exam guides (2026-10-24)
- [x] Full preparation tracks for **CCAO-F** and **CCAR-P**, with objective-level coverage matrices
- [x] 16 learning modules, from AI fundamentals to production operations
- [x] Dedicated AI security track mapped to OWASP and NIST guidance
- [x] Unofficial practice question banks for both tracks, schema-validated
- [x] Offline mock-exam engine (terminal and browser) with timed and learning modes
- [x] 20 hands-on labs that run offline in mock mode
- [x] 5 real-world projects with tests
- [x] Learning roadmaps (7, 15, 30, 60 and 90 days), flashcards, cheat sheets, interview prep and troubleshooting
- [x] CI: validation, link checks, tests, lab smoke tests, markdown lint and secret scanning
