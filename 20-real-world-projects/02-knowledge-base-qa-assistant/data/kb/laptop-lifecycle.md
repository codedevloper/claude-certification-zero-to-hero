# Laptop lifecycle standard

Owner: End User Computing, Acme Logistics. Version 3.1, reviewed 20 January 2026. Synthetic standard for training use.

## Refresh cycle

Standard laptops are replaced every four years. Engineering and data science laptops are replaced every three years because of heavier workloads. You receive an email from End User Computing eight weeks before your refresh date.

## Returning old devices

Return your old laptop within ten business days of receiving the new one. End User Computing wipes the disk using a certified erasure tool and records the certificate against the asset tag. Devices that cannot be wiped are physically destroyed by an approved disposal vendor.

## Lost or stolen laptops

If a laptop is lost or stolen, report it to the Security Operations Centre within one hour of noticing, using the phone number on the back of your badge or the security incident form. Security Operations will lock and remotely wipe the device. You must also file a police report for theft and attach the reference number to the incident.

## Personal use

Limited personal use is allowed, provided it does not involve installing unapproved software or storing personal files larger than 5 gigabytes.
